# Завдання 7 — Кількість днів до заданої дати

## Опис
Програма визначає, скільки днів залишилося до заданої дати. Якщо дата вже минула, програма показує, скільки днів минуло.

## Використані технології
- Python
- Модуль `datetime`
- Умови `if`, `elif`, `else`
- Функція `input()`

## Як працює програма
1. Користувач вводить рік, місяць і день.
2. Програма отримує поточну дату.
3. Обчислює різницю між датами.
4. Виводить результат на екран.
